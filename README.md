# SaKit

جعبه‌ابزار مدرن، امن و کاملاً درون مرورگر برای پردازش، رمزگذاری، رمزگشایی و تبدیل داده‌ها و کانفیگ‌ها.

تمام فرآیندها **۱۰۰٪ در سمت کلاینت (مرورگر شما)** انجام می‌شوند و هیچ داده یا فایلی به هیچ سروری ارسال نمی‌شود.

- **مشاهده نسخه آنلاین**: [https://amirstillalive.github.io/SaKit/](https://amirstillalive.github.io/SaKit/)
- [English Documentation](README_EN.md)

## 🛠 ابزارهای موجود

SaKit با معماری ماژولار طراحی شده تا افزودن ابزارهای جدید به سادگی انجام پذیرد. ابزارهای فعلی:

### ۱. Base64 Encoder / Decoder
- رمزگذاری و رمزگشایی متن و فایل به Base64 و بالعکس.
- پشتیبانی کامل از **UTF-8 واقعی** (متن‌های فارسی، علائم نگارشی و ایموجی‌ها بدون به هم ریختگی).
- پشتیبانی از استانداردهای Base64 و Base64URL و ترمیم خودکار Padding.
- قابلیت آپلود فایل، نمونه آماده، کپی و دانلود خروجی.

### ۲. رمزگشایی کانفیگ‌های NPV Tunnel (.npvt و .npvs)
- باز کردن فایل‌های کانفیگ **`.npvt`** (رمزگذاری AES-128 در حالت CTR با جدول‌های عمومی White-box).
- باز کردن فایل‌های **`.npvs` نسخهٔ ۱ و ۵** با الگوریتم ChaCha20-Poly1305 و جدول‌های ریاضیاتی White-box نسل ۲ (`gen2`).
- استخراج و ساخت لینک‌های مستقیم و آماده برای پروتکل‌های **VLESS** (با پشتیبانی از Reality و TLS)، **VMess**، **Trojan**، **Shadowsocks** (شامل نسخه‌های مدرن 2022) و پراکسی‌های SOCKS5/HTTP.
- پشتیبانی از پردازش همزمان دسته‌ای (Batch Decryption)، فیلتر بر اساس پروتکل، جست‌وجو و دانلود خروجی کامل JSON.

## 🚀 ویژگی‌های کلیدی و معماری

- **۱۰۰٪ آفلاین و امن (Zero-Server-Transmission)**: تمامی پردازش‌ها و محاسبات رمزنگاری در جاوااسکریپت درون مرورگر انجام می‌شود.
- **پشتیبانی کامل PWA و Service Worker**: پس از اولین بارگذاری، برنامه و تمام جدول‌های محاسباتی کش شده و حتی بدون اتصال اینترنت کار می‌کند.
- **سیستم ناوبری مدرن (Path Routing)**: پشتیبانی همزمان از SPA routing در GitHub Pages (به همراه `404.html` خودکار)، Cloudflare Pages و Vercel.
- **واسط کاربری دورگه و واکنش‌گرا**: بر پایه **React 19**، **Tailwind CSS v4** و توکن‌های طراحی تیره‌رنگ به همراه سایدبار جمع‌شونده برای دسکتاپ و منوی همراه برای موبایل.
- **دو زبانه کامل (فارسی / English)**: با تغییر لحظه‌ای چیدمان راست‌چین (RTL) و چپ‌چین (LTR).

## 💻 توسعه و اجرای محلی

### پیش‌نیازها
- Node.js نسخه ۱۸ به بالا
- npm یا pnpm

### نصب و راه‌اندازی
```bash
# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه لوکال
npm run dev

# ساخت نسخه پروداکشن (خروجی در پوشه docs/ برای GitHub Pages)
npm run build

# اجرای آزمون‌های سرتاسری و پاریتی
npm test
npm run test:e2e
```
