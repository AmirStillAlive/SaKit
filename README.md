# SaKit

ابزار تحت وب و ساده برای تبدیل و رمزگذاری متن و فایل به Base64 و بالعکس.

این ابزار کاملاً در سمت مرورگر اجرا می‌شود و داده‌های شما به هیچ سروری ارسال نمی‌شوند.

- مشاهده نسخه آنلاین: https://amirstillalive.github.io/SaKit/
- [English Documentation](README_EN.md)

## قابلیت‌ها

- تبدیل متن به Base64 و بالعکس با پشتیبانی کامل از UTF-8 (متن‌های فارسی، علائم نگارشی و کاراکترهای یونیکد)
- پشتیبانی از Base64 استاندارد و Base64URL
- اصلاح خودکار پدینگ در صورت ناقص بودن کاراکترهای تراز پایانی
- امکان انتخاب فایل و دریافت داده‌های کدگذاری شده آن
- گزینه‌های کپی، دانلود نتیجه در قالب فایل متنی، پاک‌سازی و جابه‌جایی مقادیر
- واسط کاربری دو زبانه (فارسی و انگلیسی) با چیدمان راست‌چین و چپ‌چین
- اجرای کاملاً مستقل و آفلاین بدون نیاز به اتصال به اینترنت

## اجرای محلی

این پروژه به مرحله Build یا نصب پکیج نیاز ندارد. برای اجرا کافی است فایل `index.html` را در مرورگر باز کنید یا با یک وب‌سرور محلی ساده آن را فراخوانی کنید:

```powershell
start index.html
```

یا با استفاده از سرورهای محلی:

```powershell
# با استفاده از Node.js
npx serve .

# یا با استفاده از پایتون
python -m http.server 8000
```

سپس آدرس محلی (مانند `http://localhost:8000`) را در مرورگر باز کنید.

## ساختار فایل‌ها

```text
index.html       # رابط کاربری و چیدمان المان‌ها

.nojekyll        # سازگاری با GitHub Pages
README.md        # مستندات فارسی
README_EN.md     # مستندات انگلیسی
```
